# Course Management System — Screenshots

This folder contains screenshots demonstrating the user interface and functionality of the full-stack Course Management System.

## Screenshots Included

* **Login Page:** Shows the login form for authenticated access.
* **Dashboard:** Displays the available courses in a table.
* **Add Course:** Demonstrates the form used to add a new course.
* **Edit Course:** Shows the form for updating course information.
* **Course Management:** Demonstrates the course listing and available management actions.

These screenshots illustrate the React frontend, course management interface, and integration with the Django REST Framework backend.

## Technologies Used

* React
* JavaScript
* Bootstrap 5
* Django REST Framework
* JWT Authentication
* SQLite
